# stay-on-the-line

Two exercises in speaking a protocol over one socket.

- `part1-http11/` — an HTTP/1.1 calculator that keeps the connection open.
- `part2-binary/` — BHTTP/1: a binary framing of HTTP, a server, a client, and the spec between them.

Python 3.9+, standard library only. No frameworks, no `http.server`, no `requests`.
